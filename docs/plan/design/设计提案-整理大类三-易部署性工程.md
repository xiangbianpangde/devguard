## 背景

### 当前的设计
install.sh/install.ps1 引导（各 ~120 行）→ setup_scaffold.py（515 行）读显式 manifest 原子写入 → git init + venv + 双阶段 hooks；支持 --dry-run/--verify/--install；ECC hooksPath 串联不覆盖。

### 解决的问题
单命令初始化；不夹带模板垃圾；失败回滚；不碰全局配置；跨平台三路等价。

## 目标
ensurepip 预检 fail-closed；失败清理无残留；ruff 钉版零漂移；新增 selfcheck.sh 全新环境一键自检。

## 方案（六问结论）

| 问题 | 结论 |
|------|------|
| 当前存在的问题 | ensurepip 无预检（技术债 #7）；失败残留（#7）；ruff 0.11.7 vs 0.15.20 漂移（#6）；verify 只查钩子在场 |
| 结构性问题 | bash/ps1 行为一致性无测试（#5）；脚手架与真源同源靠文档约定无机器校验 |
| 未考虑到的问题 | 幂等性（重复 install）；离线安装路径；企业内网 pip 源；无 git 机器极端场景 |
| 怎样解决 | ① ensurepip 预检 ② 失败清理 ③ ruff 对齐 + 一致性测试 ④ scripts/selfcheck.sh E2E 自检 ⑤ manifest 与实际文件比对校验 |
